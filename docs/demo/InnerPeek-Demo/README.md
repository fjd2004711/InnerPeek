# InnerPeek Demo

这是一个用于测试 Finder Quick Look 树形预览的示例目录。

- `01-Documents/02-Nested/`：二层目录，含 PDF、JSON、Swift、JavaScript、Python、HTML、CSS、XML、YAML、CSV、RTF、LOG、TXT、Markdown、PNG，以及 Word（DOCX）、Excel（XLSX）、PowerPoint（PPTX）三种 Office 格式。
- `02-Assets/` 与 `03-Data/`：分组示例文件，方便查看不同扩展名的系统图标。
- `04-Office/`：独立的 Office 三件套图标示例。
- `InnerPeek-ZIP-Demo.zip`：同一组目录和文件的 ZIP 示例，不含 `.DS_Store`。
